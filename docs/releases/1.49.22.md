# hxmy proxy 1.49.22

本版在 1.49.16 基础上完善“访问”页的筛选、排序和状态说明。

## 访问筛选

- 新增独立的状态与路由筛选，最右侧仍为排序。状态包含进行中、已结束、失败、被拦截及记录不足；路由包含 Direct、Proxy、Blocked 和 Unknown。
- 两个筛选必须命中同一次保留访问，避免把一次直连与另一次代理失败错误组合。
- 同一域名＋同一协议始终合并成一行，多次访问保留在详情中。五条摘要、完整列表、搜索和暂停继续可用。
- 当前规则与匹配的历史访问分别显示；累计流量保持原口径，不将其误标成某一路由的流量。

## Unknown 与界面细节

- 避免已知路由因为统计和请求记录的刷新时间不同而短暂进入 Unknown。收到统计后直接读取最新请求详情，不再用活跃连接数与进行中请求数的差额推断未知。
- HTTP 复用时，一个客户端连接可完成多次请求；请求已结束而连接仍打开时，不会因此误判 Unknown，连接复用本身保持。
- 真实缺少记录、记录被淘汰或关闭诊断日志时，Unknown 仍明确保留，不默认改算 Proxy。
- 筛选、排序按钮和菜单文字居中，箭头不挤偏文字；窄屏和大字体自动换行。
- 状态筛选使用“已结束”，详情中的 Transferred 改为“已结束·有流量 / Closed with traffic”；有传输不代表网页加载成功。

## 安装与验证

- **APK** 用于直接安装。同证书覆盖更新可保留本地数据；签名不同的版本不能直接覆盖，使用对应签名的更新渠道。
- **AAB** 用于 Google Play 上传，不是直接安装文件。此次 GitHub 发布不代表已提交或上线 Google Play。
- Android 10及以上，包名 `com.mzstd.hxmyproxy`，versionCode **262**。
