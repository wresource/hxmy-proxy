# hxmy proxy 1.48.76

这次更新汇总了上一正式版 1.40.0 之后的工作。主要变化是更容易找到连接信息、看清访问流量，以及处理访问失败；同时修复了已确认的列表闪退和网络边界问题。

## ✨ 连接与排障

- 全新“运行 / 规则 / 设置”工作台。概览常显代理 IP 和 HTTP、SOCKS5、PAC 端口，接入网络和端口可以就近调整，共享仍使用左右开关。
- “访问”直接展示接入设备及各自用量、域名流量、活跃连接和访问结果。摘要保留前五个域名，完整列表单独打开，支持搜索、排序和暂停查看。
- 域名详情可查看命中规则、相关连接和日志，直接调整代理、直连或拦截。最近20次快捷规则修改保存在本机，跨重启保留；恢复会检查后续编辑，避免覆盖新修改。
- 客户端接入说明更清楚。二维码打开配置指引；支持的 Apple 客户端可下载并在系统设置中安装 Wi-Fi 代理描述文件。

## ⚡ 稳定性与网络

- 修复访问列表重复条目及混合流量状态导致的两类闪退问题，补充崩溃进程和会话证据。
- 改善系统 DNS 与备用解析的超时、共享查询取消及网络切换处理，修正出口健康复检和资源回收边界。
- 保留独立的 Outbound 与 Direct egress。固定直连出口不在线时说明具体原因，不会悄悄换到其他出口。
- 修复并发连接计数、停止后重启以及日志开关的状态一致性问题。

## 🎨 界面打磨

- 复杂详情统一为底部面板，主要操作更容易找到；中英文和应用字体设置在弹层中保持一致。
- 统一同类控件的圆角、点击反馈和数字基线；修正按钮挤压、端口对齐，以及窄屏和大字体显示。
- 修复规则集和出口统计首项被隐藏的问题。Inbound 优先显示常用的 IPv4，IPv6 支持和原有选择状态保持。

## 📦 安装与文件

- **APK**：Android设备直接安装，用同一证书覆盖更新即可保留数据，无需卸载旧版。
- **AAB**：用于Google Play上传，不是直接安装包。
- Android 10及以上；包名`com.mzstd.hxmyproxy`，versionCode **239**。
- 更新后仍需在各客户端配置代理；应用不自动接管全部设备流量。停止共享后，不再使用代理的客户端应关闭其代理设置。

签名证书SHA-256：`543ec9c12d349427e0bd396369a94e8a48876c21515a277891705c3dbb76293b`。文件SHA-256另见发布附件`SHA256SUMS.txt`，两种校验值含义不同。
