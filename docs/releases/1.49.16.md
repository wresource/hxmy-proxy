# hxmy proxy 1.49.16

本次更新汇总正式版 1.48.76 之后的规则管理、导入稳定性和规则生效反馈改进。

## 规则导入与大列表

- 规则首页直接添加或导入 TXT，支持选择文件、粘贴、预检、错误行查看、追加或确认替换，并提供修改回执和撤销。
- 修复大规则文件导入时因整块超长文本排版导致的闪退。摘要只显示前5条，完整列表每页查询50条，浏览与搜索按需读取。
- 内置大规则集可完整浏览、搜索、导出并创建可编辑副本，保留分类开关、订阅及原有规则操作。
- 支持IPv4、IPv6、CIDR，以及同一行用连字符或空格分隔的起止IP范围；范围转换为等价CIDR，无需展开每个地址。
- 重叠或冲突提示关联具体规则和来源，可查看、停用或保留继续。域名与IP范围的关联仅使用实际连接证据，不自动改变域名分流或DNS行为。

## 规则生效与故障恢复

- 修复运行中规则重建失败后，界面只显示已保存开关、未明确提示修改没有生效的问题。运行页与规则页现在区分已保存、正在应用、已生效和失败，提供重试及日志入口。
- 更新失败保留旧完整规则；读取失败自动重试次数有限，停止或更新配置会使旧重试失效，避免旧任务覆盖新规则。
- 没有旧直连/拦截保护且新保护加载失败时停止共享，关闭监听及已有连接，防止继续按默认代理转发。排除故障后需手动重新开始；有意使用空配置仍然支持。
- 保留启动前完整规则校验、原有优先级和作用域、独立Direct egress及直连失败不回落VPN的行为。
- 改善错误/崩溃日志筛选和完整堆栈展示，避免较早的错误被最新普通日志挤出筛选结果；规则加载失败记录具体原因与实际生效状态。
- 调整中英文、大字体与横屏的提示布局，保持IP、端口和共享操作可用。

## 安装与文件

- **APK**：直接安装，使用原签名覆盖旧版可保留数据，无需卸载。
- **AAB**：用于Google Play上传，不是直接安装文件。
- Android 10及以上；包名 `com.mzstd.hxmyproxy`；versionCode **256**。
- 签名证书SHA-256：`543ec9c12d349427e0bd396369a94e8a48876c21515a277891705c3dbb76293b`。各文件SHA-256见附件 `SHA256SUMS.txt`。

本地验证：632项JVM测试、57项Android原生回归通过；Release R8包在受控Android VPN下22次实际请求结果符合预期，覆盖直连、拦截和默认代理。正常保留数据升级未复现普遍性规则失效；本次修复针对已确认的运行中规则加载失败及其提示/恢复缺口，不将受控故障当作每位用户现场的确定原因。

## English

- Import TXT rules directly from Rules, preview invalid lines, append or replace, and undo changes. Large lists now load and search in pages; built-in lists support full browsing, export and editable copies.
- Fix the crash caused by laying out a large imported file as one unbounded text field. Support IPv4/IPv6, CIDR and hyphen- or space-separated IP ranges without expanding every address.
- Show relevant rules when changes overlap or conflict. IP rules still match IP-address requests; observed connection hints do not change hostname routing.
- Distinguish saved settings from active rules. Failed updates keep the previous complete table and expose retry and logs. If new Direct/Block protection cannot load and no previous protection is active, sharing and existing connections stop until explicitly restarted.
- Preserve startup validation, rule precedence, Direct egress and existing DNS behavior. Improve error-log filtering, stack-trace visibility and large-text status layouts.

Use the APK for installation and the AAB for Google Play. Local checks cover the exercised scenarios; the confirmed hot-update failure is not evidence that every upgrade loses its rules.
