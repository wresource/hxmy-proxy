# hxmy proxy 1.5.0

本版接续 **1.49.72（312）**，Android versionCode 提升到 **315**，重点改善 DNS 缓存、异常解析提示、共享重启和常驻通知，并补充兼容配套可读取的错误诊断。

## 本次变化

- **DNS缓存更稳定。** 达到容量上限时先清除过期项，再局部淘汰最久未使用的记录，避免清空整表造成重复解析。保留30秒有效期、512个组合键上限、同域名查询合并及DIRECT/PROXY与网络代次隔离；缓存命中不延长有效期，规则仍在解析前判定。
- **异常解析有恢复与明确说明。** 公网域名解析为全私网地址时，在既有预算内尝试一次同出口新鲜查询；仍无合法答案则保留局域网保护，并提示检查DNS或网络登录页。明确区分DNS暂时繁忙、解析失败与出口问题，避免误导用户切换直连规则。现有有界备用解析继续保留。
- **共享重启状态更可靠。** 修复旧监听任务退出时可能覆盖新监听端口状态的竞态，保留原启动、停止和资源回收逻辑。
- **减少重复通知刷新。** 相同显示内容不重复提交通知，流量与连接数变化有界合并；启停、规则加载失败和重要状态即时处理，语言改变、停止和新启动不会被排队的旧通知覆盖。
- **连接诊断更清楚。** 增加低频大流量进度与DNS缓存统计；本地已知HTTP失败可携带可选的稳定错误码和阶段。兼容Mac配套可显示这些原因，原HTTP状态、重试语义、认证、规则来源及成功隧道内容保持。接口见[失败诊断约定](../proxy-failure-diagnostics.md)。

客户端全部直连、`.cn`后缀规则、规则列表改进及持续单向传输的空闲判定已在1.49.72发布，继续保留。App仍为普通无root的Android代理服务，局域网目标代理默认关闭，不新增VpnService。

## English

This release follows **1.49.72 (312)** with Android versionCode **315**.

- Keep useful DNS cache entries when capacity is reached: remove expired entries first, then evict only the least recently used entries needed. Preserve TTL, network/route isolation, shared lookups and rule precedence.
- Improve bounded recovery and guidance when public hostnames resolve only to private addresses. Distinguish temporary DNS congestion from lookup and egress failures while retaining local-network safeguards and existing fallback DNS.
- Fix a listener restart race that could overwrite the newly bound port's status.
- Deduplicate and coalesce notification updates independently of immediate service lifecycle decisions. Preserve language changes, stop actions and protection against stale queued updates.
- Add low-frequency transfer and cache diagnostics, plus optional typed failure metadata for compatible companions. HTTP status, retry semantics, authentication and successful tunnel bytes are unchanged.

Validation: 896 JVM tests, 13 Android native regressions, Release/R8 and Lint (0 errors, 11 existing/dependency warnings). Both Pixel Folds and the Pixel Tablet received a data-preserving update. Google Play rollout is separate from GitHub publication.
